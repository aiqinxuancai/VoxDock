VoxDock Windows 免安装版
========================================

【快速开始】
1. 解压整个文件夹到任意位置（建议不要放在 C:\Program Files 下）
2. 双击 VoxDock.exe，稍等片刻浏览器会自动打开 http://127.0.0.1:8000
3. 在「平台配置」中填写火山引擎 / 阿里云百炼 / MiniMax / 智谱的 API Key 即可使用
4. 关闭黑色命令行窗口即可退出程序

首次运行如果出现「Windows 已保护你的电脑」提示，请点击「更多信息」→「仍要运行」
（程序未做代码签名，可在 GitHub 上查看源码与构建过程）。

【数据与配置】
- data\ 文件夹：音色库数据库、参考音频与合成音频，备份或迁移时复制此文件夹即可
- .env 文件（可选）：将 .env.example 复制为 .env 后编辑，常用配置如下：
    VOXDOCK_PORT=8000              端口（被占用时会自动顺延）
    VOXDOCK_HOST=0.0.0.0           允许局域网内其他设备访问（默认仅本机）
    VOXDOCK_ADMIN_PASSWORD=xxx     管理员密码（开启局域网访问时强烈建议设置）
    VOXDOCK_NO_BROWSER=1           启动时不自动打开浏览器
- 若程序所在目录不可写，数据会保存到 %LOCALAPPDATA%\VoxDock\data

【可选：音频格式转换】
将 ffmpeg.exe 放到 VoxDock.exe 同一目录后，上传 m4a / flac / webm 等格式时会自动转换为平台支持的格式。
浏览器录音与 wav / mp3 文件无需 ffmpeg。

【API 调用】
程序运行后访问 http://127.0.0.1:8000/docs 查看接口文档，或在网页「API 接入」页面查看调用示例。

【升级】
下载新版本后，把旧版本的 data 文件夹和 .env 复制到新版本目录即可。

项目主页与更多说明请见 GitHub 仓库 README。
